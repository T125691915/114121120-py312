# 色碼電阻計算程式

這個專案包含一個以 Python 撰寫的命令列色碼電阻計算程式，可依照電阻上的 4、5 或 6 個色環計算阻值、誤差，以及（六色環時）溫度係數。

## 環境需求

- Python 3.12 以上
- 無第三方套件需求

## 執行方式

在專案根目錄執行：

```powershell
python "02-色碼電阻的計算.py"
```

程式會先詢問色環數量，再依序輸入每一環的數字代碼。輸入 `q` 可結束程式。

## 色碼對照

| 輸入數字 | 顏色 |
|---:|---|
| 0 | 黑 |
| 1 | 棕 |
| 2 | 紅 |
| 3 | 橙 |
| 4 | 黃 |
| 5 | 綠 |
| 6 | 藍 |
| 7 | 紫 |
| 8 | 灰 |
| 9 | 白 |
| 10 | 金 |
| 11 | 銀 |
| 12 | 無色 |

一般數字色碼 0 到 9 同時作為有效數字及倍率使用。金、銀可作為倍率或誤差色；無色可作為誤差色。

## 輸入順序

- **4 色環**：前兩環有效數字、第三環倍率、第四環誤差。
- **5 色環**：前三環有效數字、第四環倍率、第五環誤差。
- **6 色環**：前三環有效數字、第四環倍率、第五環誤差、第六環溫度係數。

例如四環依序輸入 `2`、`7`、`3`、`10`，代表紅、紫、橙、金，結果為 **27 kΩ，±5%**。

程式會以 Ω、kΩ、MΩ 或 GΩ 等單位顯示阻值。六色環結果另外顯示溫度係數（ppm/°C）。
